# Contributing

We welcome feedback and contributions to improve these skills.

## Feedback

Please open an issue to share your feedback, suggestions, or bug reports.

## Pull Requests

We welcome pull requests for skill improvements, bug fixes, and new skills. Please ensure your changes follow the existing skill structure and conventions.

## Skill Structure

Each skill should follow this directory structure:

```
skills/<skill-name>/
  SKILL.md          # Core skill definition (required)
  guides/           # Detailed guides (optional)
  examples/         # Few-shot examples (optional)
  tools/            # Accompanying tools/scripts (optional)
  prompts/          # System prompts (optional)
  scripts/          # Utility scripts (optional)
```
